# Multimodal Learning Roadmap

## 仓库介绍

这是我的三个月多模态算法实习冲刺学习记录仓库，用于沉淀多模态算法学习过程中的笔记、代码练习、实验记录和项目成果。

## 三个月目标

- 系统掌握 Transformer、CLIP、BLIP、LLaVA、Qwen-VL 等多模态基础模型与关键思想
- 完成从理论学习到代码复现、实验分析、项目实践的闭环
- 积累可展示的多模态检索、文档问答和部署相关项目经验

## 当前学习重点

- Transformer 与 Self-Attention 基础
- PyTorch 实现 scaled dot-product attention
- 建立每日学习记录和项目目录结构

## 文件夹结构

- `daily_logs/`：每日学习记录和每周总结
- `notes/`：模型与算法学习笔记
- `code_practice/`：小型代码练习与核心模块实现
- `experiments/`：实验配置、结果记录和分析
- `projects/`：阶段性项目实践
- `assets/`：图示、结果表格等素材

## 每日记录规范

每天在对应周目录下更新 `dayXX.md`，记录今日目标、今日完成、核心理解、代码产出、遇到的问题和明日计划。
